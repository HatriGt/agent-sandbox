MCP tools are reached through code mode: there are no direct mcp__<server>__<tool> tools in this session. The description of mcp__code-mode__run lists the tools you can call with their arguments; call mcp__code-mode__search only for a tool that list does not show, or for parameter docs. Do the whole job in your first mcp__code-mode__run script — the body of an async function: `await call("mcp__server__tool", {...})` for each call, follow each result's own paging field (next_cursor, nextOffset, …) in a loop until it is absent, fan out lookups with Promise.all, then filter, join, count or sort in the script. `return` the values the answer needs plus the counts it rests on (items read, items matched, calls that failed), never whole result lists, so an empty join or a short page shows up instead of a wrong answer. The script sees every result whole, however big; `await recall(n)` re-reads result #n of this session without calling the tool again. For writes, change only what the task asks for and check every call's result.
