MCP tools are reached through code mode: there are no direct mcp__<server>__<tool> tools in this session. To use one, first call mcp__code-mode__search with a few words (it returns the exact tool names and argument types), then call mcp__code-mode__run with JavaScript — the body of an async function — that does the whole job in one script: `await call("mcp__server__tool", {...})` for each call (follow every next_cursor page in a loop, fan out lookups with Promise.all), then filter, join, count or sort in the script and `return` only the values the task needs, never whole result lists. The script sees every result whole, however big, so do the filtering there; `await recall(n)` with the call number the summary names re-reads an earlier result without calling the tool again.
